Заметки по курсу «Основы»

Ошибка → Дефект → Сбой
Ошибка ( недоразумение ): действие человека, вызвавшее проблему.
Дефект ( ошибка ): следствие ошибки в коде .
Сбой : дефект, проявляющийся во время работы системы.

Git — это программа контроля версий, которая работает на вашем компьютере; 
GitHub — это веб-сайт, который размещает репозитории и добавляет запросы на слияние (PR), 
обзоры и системы непрерывной интеграции (CI).
